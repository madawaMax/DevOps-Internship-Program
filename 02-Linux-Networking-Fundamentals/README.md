# Linux Networking Fundamentals

## Project Overview

This project is part of my **DevOps Internship Program** and focuses on building a strong foundation in Linux networking. The project combines networking theory with practical Linux administration, troubleshooting, and documentation.

---

## Objectives

- Understand networking fundamentals
- Learn the OSI and TCP/IP models
- Understand IPv4 and IPv6 addressing
- Learn subnetting basics
- Configure and troubleshoot DNS and DHCP
- Understand common network protocols
- Configure Linux firewalls
- Practice Linux network troubleshooting
- Build hands-on networking skills for DevOps

---

## Technologies Used

- Ubuntu Server 24.04 LTS
- VirtualBox
- Linux CLI
- Git
- GitHub
- UFW Firewall
- OpenSSH
